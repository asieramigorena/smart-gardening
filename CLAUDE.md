# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Smart Gardening: an IoT urban gardening system that decides on plant care (e.g. watering) from soil readings, temperature and light sensors, combined with rain forecasts. (The README's "floor lecture" is a literal translation of the Spanish *lectura del suelo*, meaning soil readings.)

## Current state

The repository is at a very early stage: it contains only `README.md` and an empty `ML/src/` directory, which is intended for the machine-learning component. There is no build system, dependency manifest, test suite or linter configured yet, so there are no commands to document. Update this file once a language, tooling and module layout are chosen.
